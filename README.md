# AgentToybox
A playful building Agentic AI. It focuses on reproducible demos, clear walkthroughs, and practical patterns—from “hello agent” to tool-use, memory/RAG, planning, evaluation, and production readiness. Less hype, more runnable code.  可爱俏皮但工程优先的智能体 Playground，专注于 Agentic AI 的可复现 Demo、清晰讲解与实用模式，从入门到进阶覆盖工具调用、记忆与 RAG、规划执行、评测基线与生产化落地。少点自嗨，多点跑通。
